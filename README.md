# Runner 🏃‍♂️

Personal running coach system for tracking workouts, managing training plans, and progressing toward a sub-20:00 5K.

## Structure

```
running/
├── README.md
├── .gitignore
└── running-coach/
    ├── SKILL.md              ← AI Running Coach skill definition
    └── references/
        ├── user_metrics.md         ← Physical profile, HR zones, PBs, biomechanics
        ├── past_runs.md            ← Complete chronological run log
        ├── important_observations.md ← Critical biomechanical & physiological findings
        ├── coaching_logs.md        ← Session autopsies, coach feedback, week reviews
        └── coaching_plan.md        ← Active training plan & 9-month macrocycle roadmap
```

## Files

- [`running-coach/SKILL.md`](running-coach/SKILL.md): AI Running Coach skill definition — brutally honest elite endurance coach persona targeting sub-20:00 5K.
- [`running-coach/references/user_metrics.md`](running-coach/references/user_metrics.md): Athlete profile, Karvonen HR zones, biomechanics data, personal bests, hardware.
- [`running-coach/references/past_runs.md`](running-coach/references/past_runs.md): Full log of all completed runs.
- [`running-coach/references/important_observations.md`](running-coach/references/important_observations.md): Critical findings on biomechanics, cardiac drift, injury flags.
- [`running-coach/references/coaching_logs.md`](running-coach/references/coaching_logs.md): Dated session autopsies and coaching decisions.
- [`running-coach/references/coaching_plan.md`](running-coach/references/coaching_plan.md): Active weekly plan and 9-month macrocycle roadmap to sub-20 5K.
