## Formatting Guide for New Entries

- **Date**: YYYY-MM-DD
- **Type**: Easy / Flush / Recovery / Tempo / Intervals / LSD / Time Trial / Race
- **HR**: Always log both Avg and Max if available.
- **Cadence**: SPM (steps per minute, both feet). If watch logs single-foot: multiply by 2.
- **RPE**: 1–2 (Recovery) | 3–4 (Easy) | 5–6 (Moderate) | 7–8 (Hard) | 9–10 (Redline)
